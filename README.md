# Strateji ve Roguelike · Strategy & Roguelike (merkez-strateji-ve-roguelike)

Strateji ve Roguelike ailesinin **merkez uygulaması**: 7 oyunu tek mağaza uygulamasında toplar. Her oyun kendi deposundadır; ortak motor [strateji-motoru](https://github.com/taktemurr-ops/strateji-motoru), ortak çekirdek [studio-core](https://github.com/taktemurr-ops/studio-core). Her bölüm üretilir ve yapay zekâ oyuncuyla kazanılabilirliği denetlenir; kazandıkça ustalık puanı toplanır ve her oyunda beş kalıcı kazanım açılır.

| Oyun | Depo |
|---|---|
| Zindan Keşfi | [oyun-zindan-kesfi](https://github.com/taktemurr-ops/oyun-zindan-kesfi) |
| Deste Seferi | [oyun-deste-kurma](https://github.com/taktemurr-ops/oyun-deste-kurma) |
| Issız Kıyı | [oyun-hayatta-kalma](https://github.com/taktemurr-ops/oyun-hayatta-kalma) |
| Altıgen Savaş | [oyun-altigen-savas-oyunu](https://github.com/taktemurr-ops/oyun-altigen-savas-oyunu) |
| Sıra Tabanlı Taktik | [oyun-sira-tabanli-taktik](https://github.com/taktemurr-ops/oyun-sira-tabanli-taktik) |
| Kum Saati Arenası | [oyun-kum-saati-arenasi](https://github.com/taktemurr-ops/oyun-kum-saati-arenasi) |
| Vadi Kurucu | [oyun-vadi-kurucu](https://github.com/taktemurr-ops/oyun-vadi-kurucu) |
